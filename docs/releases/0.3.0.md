# Magicite 0.3.0

0.3.0 is the governed integrity-recovery release prepared from the full 0.2
code, functionality, implementation, provenance, and supply-chain audit.

## Packed changes

- Resumable Dream checkpoints, monotonic lease fencing, periodic heartbeats,
  atomic migrations, fail-closed registry reconciliation, terminal sessions,
  and recoverable idempotency reservations.
- A versioned canonical routing view, independent contraindication scoring,
  shared production/evaluation activation primitives, corrected baseline-c,
  live introspection, cursor pagination, and exact cache reuse.
- An independently authored composition corpus with superseding evaluation
  results, auditable approval decisions, and executable documentation checks.
- Multiprocess lease verification and named cold/miss/hit benchmark budgets at
  1,000 and 10,000 nodes.
- Offline embeddings by default, immutable workflow inputs, digest-pinned
  container bases, signed multi-architecture images, SBOM, and provenance
  attestations.

## Native-code decision

0.3.0 keeps Python as the sole routing semantic reference. The cache and
index-reuse work removes repeated graph preparation without creating a second
implementation. A pure-C component should be reconsidered only when the
production benchmark matrix isolates a residual Python CPU hotspot and an
exact differential suite can protect semantic parity.

The local hashing-provider matrix meets the 1,000-node target but not a 100 ms
budget at 10,000 nodes (roughly 1.28 s miss p95 and 0.85 s hit p95). These
failures are retained as evidence. The production-container matrix runs as a
blocking CI evidence step; subsequent optimization should profile the scaling
path before selecting C or another native implementation.

## Publication gate

The `v0.3.0` tag is created only after the protected pull-request workflow,
independent review, frozen acceptance suite, and release CI are green. The tag
then publishes the signed and attested GHCR image. PyPI publication remains an
explicit repository opt-in until trusted publishing is configured.
