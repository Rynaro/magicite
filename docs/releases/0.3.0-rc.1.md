# Magicite 0.3.0 release candidate 1

0.3.0rc1 is an integrity-recovery candidate. It is not a final release and
must remain behind a draft pull request until independent verification closes
the frozen acceptance criteria.

## Packed changes

- Recoverable durable-write, lease, migration, registry, session, and
  idempotency behavior.
- Separate contraindication routing, baseline parity, truthful introspection,
  and resumable body pagination.
- Corrected evaluation inputs and superseding-results policy.
- Routing-index reuse before any native-code expansion.
- One authority manifest, append-only errata, archive redirects, explicit
  prospective agent provenance, immutable workflow actions, and digest-pinned
  container build inputs.

## Release gate

The final `v0.3.0` tag requires protected `main` and release tags, required CI,
independent review, a green upgrade/crash/race suite, signed multi-architecture
images, SBOM/provenance attestations, and published corrected evaluation data.
The image digest belongs in the GitHub release record, not in pre-build package
metadata.

## Candidate verification

- Combined repository suite: 513 passed, 5 Docker-only checks skipped because
  Docker was unavailable in the verification environment.
- Ruff and mypy: clean.
- Frozen acceptance hash and declared-scope drift checks: clean.
- Supply-chain immutability and prospective provenance contracts: clean.

This candidate deliberately does not claim the final tag. The remaining
stop-ship work is the resumable Dream checkpoint/crash matrix, OS-process lease
race coverage, operator recovery for pending idempotency reservations, the
independently authored composition corpus and superseding evaluation results,
the 1k/10k production-container benchmark matrix, and activation of repository
protections described in `.github/BRANCH_PROTECTION.md`.
