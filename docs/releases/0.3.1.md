# Magicite 0.3.1

Magicite 0.3.1 adds lossless compatibility for host-authored SKILL.md files
while preserving the strict engram model used for routing and learning.

## Changed

- Preserve arbitrary Markdown bodies through import, persistence, and export.
- Preserve YAML-safe host frontmatter while keeping name and description
  compiler-owned.
- Accept colonless Use when and NOT for routing markers.
- Refuse exports when structured edits would make a preserved body stale.
- Preflight export batches before writing any target.
- Preserve unstructured procedure text in canonical engram persistence.

The change is backward-compatible for native engrams. Imported source snapshots
remain guarded against lossy export, and learning counters do not invalidate an
otherwise unchanged source body.
