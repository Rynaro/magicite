# Draft Magicite 1.0.0rc1 developer preview

Status: **proposed, unpublished**. This native-package preview is a bounded
release proposal, not v1 GA. The original acceptance criteria and archived
release gates remain intact. Engineering readiness cannot authorize publication.

## Usable scope and prerequisites

The preview offers the implemented stable `dense-v1` route/read flow, sixteen
MCP tools, explicit operator review and digest-bound L2 body retrieval with
stale-decision refusal. It does not execute skills. Keep autonomous policy false.

Use Python 3.12 and an explicit reviewed wheel or sdist, following
[candidate installation](../qualification/candidate-install.md). Before
trust-dependent commands, provision a protected root-installed enrollment
descriptor, a separate custodian account/service, explicit enrollment and journal
initialization. Follow the [operator tutorial](../operator-tutorial.md) and
[Linux custody procedure](../qualification/linux-custody.md). A simulated custodian
is only a disposable test fixture. Review and approve each imported content digest;
fetch the embedding model explicitly before offline production lookup.

## Deferred original GA obligations

Sparse/trigger/RRF routing and adaptive superiority are not advertised.
Authentic calibration, no-match labels, independent groups, temporal provenance,
a fresh final split and E2/E3/E6 remain UNEVALUATED. Reference-hardware scale,
composition/task success, autonomous learning efficacy, extra OS/Python/host
matrices, fetched OCI/PyPI/pipx/uvx channels, two-RC fingerprint qualification,
external pilots, RC-CONTRACT, EXTERNAL and GA-ALL remain unqualified. Existing
thresholds and security guards are unchanged. See the
[original UNEVALUATED catalog](../evaluation/v1/unevaluated.md).

## Publication decision remains pending

with tag `preview/v1.0.0-rc.1`, the exact reviewed wheel/sdist and checksum assets.

existing `v*` workflow unchanged: it publishes OCI first and does not explicitly
mark this native preview as a prerelease. No signed publisher provenance,

all final artifact checks and required CI, and named High-risk assessment,
mitigation/expiry/approval for PR51 F02/F09/F10/F19 by @Rynaro (Henrique Ap.
