# Magicite 1.0.0 — functional release

**Release preparation:** the maintainer approved this bounded scope and the
[four-checkpoint roadmap](v1/roadmap-proposal-2026-10-11.md) on 2026-10-11.
Publication, candidate CI and delivered-artifact verification must be recorded
in the release receipt before this document is evidence of delivery.

## Included promise

The existing local MCP workflow supports knowledge registration, digest review,
explicit admission, stable `dense-v1` retrieval, skill-body loading, governed
lifecycle operations, and Dream recovery. `magicite init --host claude` connects
an already enrolled project, preserves unrelated host configuration, verifies a
local MCP handshake, and offers separately consented model fetch/import/review.
It does not provision custody or approve content automatically.

Use Python 3.11 or 3.12 and Linux independently protected custody. Follow
[Install](../install.md), administrator [Setup](../setup.md), and
[Quick Setup](../quick-setup.md). Imported drafts require lifecycle preparation;
approval alone does not make drafts query eligible.

## Distribution

The final workflow publishes GitHub wheel/source packages with build provenance,
artifact hashes in `release-manifest.json`, and multiarch signed OCI with SBOM
and provenance. These are intended release outputs until publication is verified.
Production PyPI is deferred: `PUBLISH_TO_PYPI=false`. Prior TestPyPI rehearsal
does not establish a production trusted publisher. Use explicit GitHub wheel
instructions; do not substitute a similarly named package from an index.

OCI channel: `ghcr.io/rynaro/magicite:1.0.0`; pin the digest recorded in the
release receipt. Signature verification uses the repository's `release.yml`
GitHub Actions certificate identity and `https://token.actions.githubusercontent.com`
as the OIDC issuer. A container image is not a custody workstation installer.

## Limits and conservative operating profile

Scale/build/cold-start budgets, improved retrieval or composition quality,
production adoption, independent certification, and production macOS custody
are **unqualified**. Earlier scale runs exceeded budgets; the later native
1,000-item diagnostic showed no meaningful build improvement and was not a
qualification. No historical result is reclassified as PASS by this release.

Keep autonomous approval **off** (the default). Review exact content digests
under independent protected custody. Use the current supported runtime and
[Operations](../operations.md) restore procedures; a copied SQLite database or
hand-restored pre-hardening state is not a complete supported backup. Encrypt
operator backups containing protected authority or fingerprint key material. Do not
run an older binary against restored current authority state.

The known append-window filesystem race may leave delayed corruption or an
availability failure; current hardening is not a proof of universal filesystem
race resistance. Review failures and reconcile protected state rather than
bypassing digest/custody checks. Operator-enabled autonomous mode and mixed old
runtime/restored authority are outside this release's conservative profile.
The source-bound security review records its own disposition; general scope
approval does not certify security or accept undisclosed findings.

Model acquisition is not pinned to an expected immutable artifact ahead of
fetch. Image digests bind the resulting baked bytes but do not establish the
expected upstream model origin. Release scanning blocks fixable HIGH/CRITICAL
findings and separately emits all-severity SARIF; `ignore-unfixed=true` means a
green check is not zero-CVE proof. Actual release findings still need review.
