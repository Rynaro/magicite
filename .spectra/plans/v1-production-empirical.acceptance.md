# Production empirical diagnostic acceptance

### AC-EQ-01 (event-driven)
GIVEN an invocation labelled production retrieval or paired policy evaluation
WHEN predictions are generated
THEN execution SHALL use the actual production embedder and router dispatch or explicitly reject an unsupported production mode
VERIFY: real provider/policy call evidence and regression excluding hash-ranker fallback under a production label

### AC-EQ-02 (event-driven)
GIVEN the frozen thirty-body first-party artifact inventory
WHEN the isolated registry is built
THEN every valid declared body SHALL enter the shared candidate inventory independently of gold labels
VERIFY: contained-path and digest validation, complete ID inventory and unlabeled distractor regression

### AC-EQ-03 (unwanted-behavior)
GIVEN identical runtime queries and corpus with changed scoring annotations
WHEN production prediction runs
THEN rankings, selections and abstention SHALL remain independent of those annotations
VERIFY: query-only runtime projection and metamorphic relevance/no-match annotation test

### AC-EQ-04 (event-driven)
GIVEN an acquired task-owned production model cache
WHEN the first measurement starts
THEN expected model-byte identities SHALL already be frozen and verified
VERIFY: pre-run model/tokenizer/config manifest and offline replay provenance

### AC-EQ-05 (unwanted-behavior)
GIVEN missing or changed required model bytes
WHEN a measurement process starts
THEN execution SHALL fail before a query is evaluated
VERIFY: meaningful missing and mutated artifact controls without silent download or alternate-provider fallback

### AC-EQ-06 (event-driven)
GIVEN the independently authored sixteen-query diagnostic oracle and identical admitted snapshot
WHEN the two actual policies run
THEN paired raw predictions SHALL retain their actual policy, ordered candidates, scores, selection or abstention and digest identities
VERIFY: premeasurement source/oracle/policy freeze, real dense/adaptive-blend dispatch and scoring-only labels

### AC-EQ-07 (event-driven)
GIVEN raw paired diagnostic predictions
WHEN quality is summarized
THEN descriptive metrics SHALL be recomputable with explicit denominators and inconclusive official qualification status
VERIFY: metric reconciliation, no-match/abstention treatment, unsupported confidence null and no policy promotion

### AC-EQ-08 (event-driven)
GIVEN the frozen local timing protocol
WHEN both policy profiles execute
THEN each SHALL retain three fresh-process runs with fifty warm-ups and one thousand measured rotated operations per run
VERIFY: per-operation timings, process/environment identity, cache disclosures, distinct-query counts and per-run latency/resource summaries

### AC-EQ-09 (event-driven)
GIVEN completed empirical execution
WHEN the report is independently reviewed
THEN each result SHALL bind exact clean candidate, model, corpus, oracle, policy, environment, commands and retained raw evidence
VERIFY: digest/coverage reconciliation, focused negative tests, independent maker-checker review and current CI

### AC-EQ-10 (ubiquitous)
THEN the qualification record SHALL preserve official-corpus, reference-scale/hardware, deployment, model-authenticity, publication and human-approval limitations without rewriting historical evidence
VERIFY: explicit unresolved gate mapping and scoped diff; no full E3/E6/GA or Gauge acceptance claim
