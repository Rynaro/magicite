# Prospective interpretation C02 — verified snapshot clones on worker restart

Fresh byte-verified clones of the same admitted snapshot are permitted on each persistent worker start/restart, including recovery after timeout/interruption, under the existing exact-input resume contract. This is not a new corpus, policy, threshold, learned state or test replay. The immutable plan and ten criteria remain unchanged.

The seal must bind the actual database/vector/index/graph and other decision-affecting snapshot bytes, complete pool, model, policy/config, registry/authority identity and runtime input contract. Matching admitted IDs/content/status alone is insufficient. Create the clone from the verified snapshot; never trust a previously mutated working database merely because its ID set still matches. Preserve stable project/registry binding and custody semantics; do not regenerate enrollment or policy identities and call them the same frozen input.

Source inspection supports the scoped reset: route resolves session bookkeeping and _finalize_route appends Tier-C route events/exposure accumulators (core/router.py around1800; storage/ephemeral.py bump_route_bookkeeping). That helper does not fold exposure into durable learned state; Dream/checkpoint and feedback are outside this slice. Both fixed-policy paths must continue reading the same sealed ranking inputs. This is not permission to discard state that actually affects later selection. Independent review must confirm no learning/feedback, calibration mutation or other decision-affecting state is introduced by the runner.

Resetting only such ephemeral session/event bookkeeping and process caches on restart is disclosed in worker provenance, along with snapshot digest and worker start/restart reason. Latencies across cold/warm worker boundaries are not interchangeable; this slice makes no performance qualification claim. All completed durable query outcomes and cumulative operational budget survive unchanged. Resume only unfinished rows; never replay completed rows to restore state or select a better result.

Before full test, readiness checks must cover vector/graph tampering rejected by the sealed-snapshot path, exact clone bindings and preservation of completed rows. Source/helper tests or already-authorized train smoke may establish decision-input equivalence; no extra official-test rerun is authorized. If a decision-affecting state transition is discovered, stop and request a prospective contract decision instead of treating this note as a waiver.
