# Official retrieval observation acceptance

### AC-OQ-01 (event-driven)
GIVEN the accepted official corpus and expected production model bytes
WHEN an evaluation starts or resumes
THEN candidate, corpus, split, model and configuration identities SHALL match the frozen run contract
VERIFY: complete hash/identity checks and meaningful tampered input/model/source negative controls

### AC-OQ-02 (event-driven)
GIVEN the prospectively selected sixty-four train smoke queries
WHEN readiness is exercised
THEN each policy SHALL use the complete train candidate pool without fitting or accessing test outcomes for selection
VERIFY: deterministic original_id-group sampling, exact frozen IDs, full10123 pool and explicit smoke-only claim

### AC-OQ-03 (event-driven)
GIVEN the official test phase
WHEN isolated registry admission is checked
THEN the admitted evaluation inventory SHALL contain exactly the declared6006 native test artifacts
VERIFY: actual register/review path, exact ID/hash membership and reduced/wrong-pool rejection

### AC-OQ-04 (event-driven)
GIVEN either frozen real policy and query-only runtime input
WHEN a prediction runs
THEN it SHALL invoke actual FastEmbed and router semantics with explicit rank depth10 and unchanged default production behavior
VERIFY: exact query text, label-isolation and policy/depth/default regressions plus actual runtime call evidence

### AC-OQ-05 (event-driven)
GIVEN the fixed official test query sequence
WHEN both policy runs complete
THEN all4392 queries per policy SHALL have immutable raw outcomes including any abstentions, exclusions, errors and timeouts
VERIFY: complete unique row coverage, actual selection/ranking identities and full intention-to-test denominator

### AC-OQ-06 (event-driven)
GIVEN retained official predictions and separate scoring labels
WHEN metrics are computed
THEN decision Hit@1 SHALL count abstentions and errors as misses and remain distinct from rank-only retrieval measures
VERIFY: hand-computed scored cases, grade-aware metrics, null unsupported values and independent raw-result reconciliation

### AC-OQ-07 (ubiquitous)
THEN policy thresholds SHALL remain frozen and unsupported calibration, independent-group and hybrid promotion claims SHALL remain unavailable
VERIFY: thresholds0/0 with abstention enabled, confidence null, no fabricated negatives and explicitly descriptive query-row intervals

### AC-OQ-08 (unwanted-behavior)
GIVEN interrupted or bounded execution
WHEN work resumes or reaches an operational limit
THEN it SHALL preserve completed outcomes and reject changed bindings or duplicate selective reruns
VERIFY: checkpoint/progress/timeout/budget controls, incomplete-coverage reporting and exact-input resume tests

### AC-OQ-09 (event-driven)
GIVEN prospective source and experiment freezes
WHEN independent readiness and final review run
THEN the evidence SHALL bind actual commands, pools, model, all predictions and recomputed results to the checked candidate
VERIFY: maker-checker readiness before full test, provenance/coverage verification, focused controls and current CI
